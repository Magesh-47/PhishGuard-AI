About PhishGuard

Detection you can inspect, not a black box

PhishGuard analyzes URL structure, domain signals, and lexical patterns with a trained machine learning model — then shows you exactly why a link was flagged, not just a verdict.

Our approach

Built for clarity, not just classification

Most phishing filters give you a single yes/no signal. PhishGuard is built to show its reasoning: which URL features triggered a flag, how confident the model is, and what to do next. That transparency is what makes it useful for both individuals checking a suspicious link and teams building it into their own workflows.

The current model is trained on a labeled dataset of phishing and legitimate URLs, extracting over 30 features — length, entropy, subdomain depth, special characters, HTTPS usage, and more — before scoring each link.

How detection works

01

Trained classifier

A scikit-learn model trained on labeled phishing and legitimate URL data produces a probability score for each scan.

02

30+ extracted features

URL length, subdomain count, special-character density, HTTPS usage, and other lexical and structural signals.

03

Real-time scoring

Feature extraction and model inference both run synchronously, so you get a verdict in under a second.

04

Explained results

Each result includes the specific suspicious patterns detected and tailored next-step recommendations.

05

Signed-in users get a searchable log of past scans with risk trends over time.
